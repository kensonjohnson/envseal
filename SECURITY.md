# Security policy

Please do **not** report suspected vulnerabilities in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/kensonjohnson/envseal/security/advisories/new) for this repository. Include a minimal reproduction, affected version, impact, and any suggested mitigation. Do not include real passwords, plaintext dotenv values, or production ciphertext.

If private reporting is unavailable, contact the repository owner privately through GitHub.
